# Contributing

Thanks for helping improve this project. Small, focused PRs are welcome.

## Setup

```bash
git clone https://github.com/raimonvibe/website-editorial-eu.git
cd website-editorial-eu
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Branch naming

Use a short prefix, for example:

- `fix/short-description`
- `docs/short-description`
- `feat/short-description`

## Pull requests

1. Fork the repo (or create a branch if you have write access).
2. Make your change and keep the diff focused on one issue.
3. Open a PR that explains **what** changed and **why**.
4. Link the related issue when there is one.

## Good first issues

Look for issues labeled [`good first issue`](https://github.com/raimonvibe/website-editorial-eu/labels/good%20first%20issue).
